# What still has to be entered on OpenReview

The PDF in this directory is the anonymized TMLR submission. The style file is the official `tmlr` package without the `accepted` or `preprint` options. TMLR's author guide does not include a numbered checklist; none was added to the PDF.

Enter these on the OpenReview form. They are not in the PDF, because the review is double-blind.

- A complete OpenReview profile for every author, including conflicts and career history.
- A recommended action editor.
- The human-subjects answer. The analyses use public trial aggregates and in-vitro assay labels, not a patient cohort recruited for this study. The local IRB decision is still the authors' to record.
- Funding and competing interests. Reviewers do not see these.
- Do not paste a repository URL or a preprint link that names the authors. TMLR allows a preprint, but the submission itself must stay anonymous.
- Upload anonymized code and `results/predictions/predictions.csv.gz` plus `results/v5/v5_claims.json` as supplementary material if the form allows a zip under 100 MB.
- Read the compiled `main.pdf` before submitting. The broader-impact statement is included because misuse as a clinical safety tool is a concrete harm.

Submission page: https://openreview.net/group?id=TMLR

Author guide: https://jmlr.org/tmlr/author-guide.html
